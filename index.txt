JavaScriptda OOP (Object-Oriented Programming) haqida
JavaScriptda OOP (Ob'ektga yo'naltirilgan dasturlash) asosan prototipga asoslangan modeldan foydalanadi. Bu klassik OOP tillaridan (masalan, Java yoki C++) farq qiladi, chunki JSda ob'ektlar bir-biriga prototiplar orqali bog'lanadi. Biroq, ES6 (2015) dan boshlab class sintaksisi qo'shildi, bu OOPni an'anaviyroq qiladi. OOPning asosiy tamoyillari: encapsulation (yopiq qilish), inheritance (meros olish), polymorphism (ko'p shakllilik) va abstraction (abstraktsiya).
Eng kerakli narsalarni quyidagicha guruhlayman: asosiy tushunchalar, misollar va foydali metodlar.

1. Ob'ektlar (Objects)

JSda hamma narsa deyarli ob'ekt: sonlar, matnlar, funksiyalar va h.k. Ob'ekt — bu kalit-qiymat juftliklari to'plami.
Yaratish: Ob'ekt literali {} yoki new Object() orqali.

Misol:
let odam = {
    ism: "Ali",
    yosh: 25,
    salomlash: function() {
        console.log("Salom, mening ismim " + this.ism);
    }
};
odam.salomlash(); // "Salom, mening ismim Ali"
this kaliti: Ob'ekt ichidagi metodlarda o'z ob'ektiga murojaat qilish uchun ishlatiladi.

2. Prototip (Prototype)

JS OOPning yuragi: Har bir ob'ektning prototipi bor, u orqali meros olish amalga oshiriladi.
Prototip zanjiri (prototype chain): Agar ob'ektda xususiyat topilmasa, uning prototipida qidiriladi.

Misol (prototip orqali meros):
let hayvon = {
    ovqatlan: function() {
        console.log("Ovqatlanmoqda...");
    }
};

let it = Object.create(hayvon); // it hayvonning prototipi
it.ovoz = "Vov-vov";
it.ovqatlan(); // "Ovqatlanmoqda..." (meros orqali)

3. Classlar (Classes) — ES6+

An'anaviy OOPga o'xshash sintaksis: class kaliti bilan yaratiladi.
Constructor: Ob'ekt yaratishda ishlaydigan metod.

Misol:
class Mashina {
    constructor(marka, rang) { // Constructor
        this.marka = marka;
        this.rang = rang;
    }

    hayda() { // Metod
        console.log(this.marka + " haydamoqda");
    }
}

let bmwm = new Mashina("BMW", "qora");
bmwm.hayda(); // "BMW haydamoqda"

4. Inheritance (Meros olish)

extends kaliti bilan: Subclass superklassdan meros oladi.
super(): Superklass constructorini chaqirish.

Misol:
class ElektrMashina extends Mashina {
    constructor(marka, rang, batareya) {
        super(marka, rang); // Superklassni chaqirish
        this.batareya = batareya;
    }

    zaryadla() {
        console.log("Batareya " + this.batareya + "% zaryadlandi");
    }
}

let tesla = new ElektrMashina("Tesla", "oq", 80);
tesla.hayda(); // "Tesla haydamoqda" (meros)
tesla.zaryadla(); // "Batareya 80% zaryadlandi"

5. Encapsulation va Abstraction

Encapsulation: Ma'lumotlarni yopiq qilish. JSda _ (underscore) bilan shaxsiy xususiyatlarni belgilaymiz (konventsiya).
Abstraction: Ichki tafsilotlarni yashirish, faqat kerakli interfeysni ko'rsatish.

Misol (encapsulation):
class BankHisob {
    constructor(balans) {
        this._balans = balans; // Shaxsiy (_ bilan)
    }

    getBalans() { // Abstraktsiya orqali kirish
        return this._balans;
    }

    deposit(pul) {
        this._balans += pul;
    }
}

let hisob = new BankHisob(1000);
hisob.deposit(500);
console.log(hisob.getBalans()); // 1500

6. Polymorphism (Ko'p shakllilik)

Bir xil metod turli ob'ektlarda turli xatti-harakat qiladi (overriding orqali).

Misol:
class Shaxs {
    salomlash() {
        console.log("Salom");
    }
}

class Bola extends Shaxs {
    salomlash() { // Overriding
        console.log("Salom, bolalar!");
    }
}

let odam1 = new Shaxs();
let bola1 = new Bola();
odam1.salomlash(); // "Salom"
bola1.salomlash(); // "Salom, bolalar!"

7. Foydali OOP metodlar va maslahatlar

Object.keys(obj): Ob'ekt kalitlarini qaytaradi.
Object.values(obj): Qiymatlarni qaytaradi.
instanceof: Ob'ektning sinfini tekshirish (masalan, tesla instanceof Mashina // true).
Static metodlar: static kaliti bilan, ob'ektsiz ishlatiladi (masalan, class Matematika { static kvadrat(x) { return x*x; } } → Matematika.kvadrat(5);).
Getter/Setter: get va set bilan xususiyatlarni boshqarish.
OOP afzalliklari JSda: Kodni qayta ishlatish, modullik, oson boshqarish (katta loyihalarda muhim).
